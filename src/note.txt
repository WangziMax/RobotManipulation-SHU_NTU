离线数据我已经采集好并保存到huggingface仓库了，配置如gym_hil_env.json所示，若想自己采集并训练可更改配置并运行：
python -m lerobot.rl.gym_manipulator --config_path /home/用户名/lerobot/src/gym_hil_env.json
若不想重新采集可将mode改为null,熟悉键盘的操控
python -m lerobot.rl.gym_manipulator --config_path /home/用户名/lerobot/src/gym_hil_env.json

python -m lerobot.rl.actor   --config_path=outputs/train/2026-06-03/14-33-57_0603/checkpoints/008000/pretrained_model/train_config.json   --resume=true

流程：创建环境--policy观察环境（输入obs等18维状态，输出动作）--在环境中执行动作获取奖励--无论好不好的话就把状态动作奖励及下一步状态动作
     存起来transition--继续探索---经验够多的时候随即采样训练Critic（动作值多少钱，每一部动作带来的奖励，跟成功失败的奖励是两回事）--训练actor（问Critic怎么动Q才高）
